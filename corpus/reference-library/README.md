# Reference library — citation manifest

The six methodology-toolkit PDFs live in this directory locally but are
**gitignored** (copyrighted published papers; not redistributed here). This file
is the tracked record of what they are and how to obtain them.

Citations below are [T1] — read directly against each file's own title/byline
page — except `EValue.pdf` and `Trends_in_Quantitative_Bias.pdf`, which are
presentation materials (no formal journal citation exists to verify against);
those are tagged `[T1, non-peer-reviewed source]`.

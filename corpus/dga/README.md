# DGA corpus

`appendices.md` — the appendices to *The Scientific Foundation for the Dietary
Guidelines for Americans, 2025–2030*. As a work of the U.S. federal government it
is in the public domain, so it is tracked here. This is the audit's **back-end**:
the systematic/umbrella reviews and evidence tables that are supposed to support
the front-end claims.

Not yet included: the main ~90-page front-end report (the Scientific Foundation
proper). Add it here if/when it is brought into the repo.
